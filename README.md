# Goodoo TV

اپ تماشای هم‌زمان با Next.js 16، Tailwind، Glisse، Socket.IO، Prisma و PostgreSQL. رابط موبایلی است و حالت روشن و تاریک دارد.

## اجرا با Docker

```bash
docker compose up --build
```

اپ روی `http://localhost:3000` باز می‌شود. دیتابیس PostgreSQL در سرویس `db` است و migration هنگام راه‌اندازی اپ اجرا می‌شود.

## اجرای محلی

```bash
cp .env.example .env
npm install
docker compose up -d db
npm run db:migrate
npm run dev
```

برای ورود، شماره تلفن وارد کن و در مرحلهٔ کد از `123456` استفاده کن. فعلاً پیامک ارسال نمی‌شود. نشست کاربر با توکن تصادفی و هش‌شده در دیتابیس ثبت می‌شود و کوکی HttpOnly دارد. این OTP ثابت فقط برای نسخهٔ آزمایشی است و باید پیش از انتشار عمومی با ارسال و تأیید واقعی جایگزین شود.

میزبان لینک یوتیوب، MP4 یا HLS را وارد می‌کند. هر کاربر واردشده می‌تواند با لینک یا کد ۱۲ کاراکتری اتاق وارد شود. کنترل پخش دست میزبان است. لینک‌های مستقیم باید در مرورگر و با کدک سازگار باز شوند؛ برای HLS در مرورگرهای مبتنی بر HLS.js، منبع باید CORS را مجاز کند.

اتاق‌ها در PostgreSQL ذخیره می‌شوند. شمار افراد حاضر فقط در حافظهٔ یک فرایند Node است؛ برای چند نمونهٔ هم‌زمان سرور به Socket.IO adapter مشترک نیاز دارد.
